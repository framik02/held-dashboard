BENTORNATO

Entriamo nel progetto.

Collega la wiki GitHub del team. I contenuti restano nel repository, con i suoi permessi.

Come ottenere l’accesso

Il proprietario può creare un token fine-grained: selezionare solo la wiki e il permesso Contents: Read and write.

Se sei collaboratore di un repository personale altrui, GitHub richiede al momento un token classic con scope repo. Questo scope è ampio: usa una scadenza breve. In locale puoi usare GitHub CLI senza incollare token.

Il token rimane in memoria in questa scheda e viene inviato solo all’API GitHub. Ricaricando la pagina dovrai inserirlo di nuovo. Non inviarlo in chat.

Nessun dato della wiki è incluso nel sito pubblico.
